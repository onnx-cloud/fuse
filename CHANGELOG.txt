Fuse v1.0 (draft)

[Parser & AST]
- Added support for type syntax: `type` aliases (`type Name = f32[n+1]`).
- Added symbolic dims and expressions in type declarations (e.g., `n+1`, `m//2`).
- Added variadic/ellipsis dims support: `<T>[...]`, `<T>[batch, ...]`, and `:` shorthand for dynamic dims.
- Updated and extended `schemas/fuse.ast.schema.json` to include type aliases and symbolic dims; added validation tests.

[Lowering]
- Type aliases are resolved at lowering time and used for parameter/output shaping.
- Symbolic and non-integer dims are represented as dynamic (ONNX dim_value=0) in lowered `ValueInfoProto`.

[Ops & Syntax]
- Introduced attribute handling: postfix attribute syntax `name@=value` supported; unadorned `name=value` will be treated as an attribute when the value is a literal.
- Added `@golden` top-level test that compiles to ONNX and executes numeric checks with ReferenceEvaluator.

[Quantization]
- Replaced call-based `Quantize(x, s, z)` / `Dequantize(x, s, z)` helpers with function-level pragmas `@quantize(...)` and `@dequantize(...)` (they lower to `QuantizeLinear` / `DequantizeLinear` / `Cast` as appropriate); updated tests and examples to use the new pragmas.

[Tests & Schema]
- Added `tests/test_parser_v2.py`, `tests/test_ast_schema.py`, `tests/test_lowering_v2.py`, `tests/test_attr_syntax.py`, `tests/test_golden.py`, and `tests/test_quantize.py`.
- All tests pass on the current branch.
