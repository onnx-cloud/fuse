# Iris classification (ML tutorial)

A beginner-friendly end-to-end tutorial showing how to train a tiny classifier on the Iris dataset with NumPy, embed learned weights into a deterministic `*.fuse` model, export to ONNX, and validate the exported model.

## For beginners ✅
- Train a small 4→8→3 MLP (ReLU hidden, Softmax output) on the Iris dataset.
- Embed learned weights as `const` initializers in a `jupyter/cookbook/iris_model.fuse` file.
- Export to ONNX with `fuse onnx` and validate with `onnx.checker` and `onnx.reference.ReferenceEvaluator`.

## For experts 🔧
- Shows how to keep the pipeline deterministic (stable name allocation and seeded RNG), inline small models as constants for reproducible golden tests, and include a compact `@proof` node to validate model behavior in CI.
- Ops used: `Reshape`, `MatMul`, `Add`, `Relu`, `Softmax`, `ArgMax`.

## Assets
- `jupyter/cookbook/iris_train.py` — training script that:
  - obtains a canonical `iris.csv` (tries sklearn first and falls back to UCI download),
  - trains a small MLP in NumPy (deterministic SGD),
  - writes `jupyter/cookbook/iris_model.fuse` (weights embedded) and `jupyter/cookbook/iris_weights.npz` (optional), and
  - prints export & test commands.
- `jupyter/cookbook/iris_model.fuse` — generated by the script (checked into the repo when you run the trainer and pin the final weights), deterministic across runs when the training RNG seed is constant.

## Run & export
1. Generate dataset + trained `.fuse` model:

```
python jupyter/cookbook/iris_train.py --out-fuse jupyter/cookbook/iris_model.fuse --seed 0
```

2. Export to ONNX:

```
./.venv/bin/fuse onnx -f jupyter/cookbook/iris_model.fuse -o onnx/cookbook/iris.onnx
```

3. Validate the exported model (basic):

```
python -c "import onnx, onnx.reference as r; m=onnx.load('onnx/cookbook/iris.onnx'); onnx.checker.check_model(m); print('OK')"
```

4. Run the built-in `@proof` check in the Fuse model (runs via the cookbook test harness):

```
python -m pytest tests/test_cookbook.py -q -k iris
```

## Notes & best practices 💡
- Keep training steps small (few epochs) for tutorial speed; for gold-standard models, train to convergence and commit the final `iris_model.fuse` and `iris_weights.npz` to the `jupyter/cookbook/` folder.
- Use a fixed RNG seed for reproducibility (`--seed` flag in the trainer).
- The training script writes a `@proof` with an expected label for a selected sample so the model can be included in golden CI tests.
